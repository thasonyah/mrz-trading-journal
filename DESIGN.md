# Design System

Mode: Operate.

The interface follows the observed tradingjournal888 tone: near-black workspace, charcoal panels, compact left navigation, gold primary accent, purple/blue section labels, and small corner accents on analytical cards. It should feel like a focused trading desk rather than a marketing dashboard.

Controls use tight 6-8px radii, uppercase field labels, visible focus states, dense tables, and restrained color coding for profit/loss. Charts use green/red for outcomes and muted axes so the data remains readable against dark panels.
